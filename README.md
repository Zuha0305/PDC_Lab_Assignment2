# PDC Lab Assignment 2

**Course:** Parallel and Distributed Computing Lab (CS-426L)

This repository contains the implementation of seven questions for PDC Lab Assignment 2.

## Questions

1. **Q1 — Trading Events:** Event polymorphism
2. **Q2 — Packet Symmetry:** Stack, queue, and palindrome auditing
3. **Q3 — Telemetry:** Threads and asynchronous processing
4. **Q4 — Fork/Join:** Parallel portfolio risk calculation
5. **Q5 — Sensor Search:** Parallel minimum and maximum search
6. **Q6 — Inventory Benchmark:** Synchronized maps and concurrent maps
7. **Q7 — Cache Locality:** Row-major and column-major traversal

## Project Structure

Each question has a separate folder containing its source code and related files.
